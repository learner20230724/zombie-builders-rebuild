# 建筑工大战僵尸 / Zombie Trailer Park

[English](README.md) · [下载游戏](https://github.com/learner20230724/zombie-builders-rebuild/releases/latest)

**建筑工大战僵尸（Zombie Trailer Park）**的桌面与浏览器版本，使用 **JavaScript、Canvas 2D 和 Web Audio**。建造营地、发展经济、招募幸存者，抵挡僵尸进攻。不需要 Flash 或 Ruffle。

## 项目功能

- 四个关卡，包含单位生产、基地建设、资源管理与战斗。
- Windows 桌面版：双击 `ZombieBuilders.exe`，在独立窗口中离线游玩。
- 纯游戏界面，随窗口和浏览器全屏等比例放大。
- 各具特点的幸存者单位、僵尸类型和特殊技能。
- 自带图像与音频素材，支持本地通关进度与记录。
- 用 JSON 配置调整单位、僵尸、建筑、技能与关卡。
- 游戏内预设、当前战局改数值、波次编辑和一键生成僵尸。
- 设置与游戏并列显示，可暂停编辑，也可边玩边调。

## 默认游戏参数

以下数值来自 **[config/](config/)**。时间统一标为**战斗 tick**：默认速度为 **2**，正常运行约 **120 tick/秒**；移速为行走时每 tick 的像素数。出手间隔由各单位的动画和状态机控制，**攻击值不是 DPS，也不存在所有单位共用的固定攻速**。

### 可招募单位

| 单位 | 现金 | 人口 | 生命 | 有效攻击值 | 移速 | 训练（tick） |
| --- | ---: | ---: | ---: | --- | ---: | ---: |
| 铲兵（Shovel Man） | 50 | 1 | 50 | 近战伤害预算 10 | 0.5 | 50 |
| 愤怒农夫（Angry Farmer） | 200 | 2 | 100 | 对前方最近目标造成 15 伤害 | 0.328125 | 300 |
| 机枪皮卡（Survivalist） | 900 | 5 | 400 | 每次机枪射击事件 5 | 1.2 | 500 |
| 燃烧瓶投手（Moonshine Bomber） | 350 | 2 | 80 | 每次瓶爆伤害预算 100 | 0.25 | 300 |
| 牧师（Preacher Man） | 1,500 | 3 | 100 | 转化敌人，无直接伤害 | 0.4 | 1,500 |

铲击、机枪和爆炸可把击杀后的余伤传给后续符合条件的目标，并非每个目标都受到表中全额伤害。牧师可转化前四类僵尸，不能转化投尸者或基地。招募前置条件见下方建筑解锁关系。

### 僵尸种类与属性

| 种类 | 基础生命 | 基础攻击 | 移速 | 击杀 XP | 特殊行为 |
| --- | ---: | --- | ---: | ---: | --- |
| 普通僵尸（Zombie） | 25 | 近战 10 | 0.25 | 25 | 慢速接近、近距离攻击 |
| 跳跃食尸鬼（Jumping Ghoul） | 60 | 近战 16 | 0.5 | 60 | 跳跃突进，近距离跳咬 |
| 快速僵尸（Fast Zombie） | 150 | 近战 20 | 1.5 | 150 | 高速行走、近距离抓挠 |
| 肥胖僵尸（Big Fat Zombie） | 1,000 | 近战伤害预算 60 | 0.4 | 1,000 | 重击可在附近目标间传递余伤 |
| 尸体投掷者（Corpse Thrower） | 1,500 | 每次尸弹伤害预算 500 | 0.0625 | 1,500 | 远程投尸，落地还生成一只普通僵尸 |

尸弹在符合条件的玩家目标间共享伤害预算，不受关卡近战伤害倍率影响。击杀 XP 取配置中的基础生命值；转化不发 XP，转化后的友方僵尸死亡也不发 XP。玩家／僵尸基地生命为 **4,000／16,000**。

### 建筑

| 建筑 | 现金 | 数量上限 | 建造（tick） | 前置建筑 | 效果 |
| --- | ---: | ---: | ---: | --- | --- |
| 房车（Trailer） | 250 | 15 | 300 | 无 | 每座人口上限 +5 |
| 废料场（Salvage Yard） | 500 | 5 | 300 | 无 | 每座平均每 600 tick 收入 50 现金，合并计币 |
| 农舍（Farm House） | 1,000 | 1 | 500 | 无 | 解锁愤怒农夫 |
| 车库（Garage） | 1,500 | 1 | 500 | 农舍 | 解锁机枪皮卡 |
| 酒坊（Still） | 1,200 | 1 | 1,000 | 农舍 | 解锁燃烧瓶投手 |
| 教堂（Chapel） | 1,500 | 1 | 2,000 | 车库 | 解锁牧师 |

开局已有一座房车和一座废料场，计入数量上限。每座已完成的废料场每 tick 向共用收入池增加 1 个计币，池中每满 600 个计币发放 50 现金。

上表是原版默认值。自定义时，建筑 **`maximum: 0` 表示不设玩法数量上限**；正整数 **1–100,000** 表示上限。本局修改立即生效，不拆已有建筑、不取消已付订单；超出原图绘制位置的建筑仍真实计入收入与人口。引擎另有每类 100,000 的安全保护，并非数学意义的无限。

| --- | ---: | ---: | ---: | --- | --- |

| 收割机（Harvester） | 4,000 | 150 | 10,000 | 移速 0.6，前方范围 220 内每个僵尸每 tick 受到 100 伤害，不攻击基地 | 本地已通关第 1 关 |
| 空袭（Air Strike） | 5,000 | 150 | 10,000 | 3 架移速 6 的飞机投弹，每枚炸弹爆炸伤害预算 500 | 本地已通关第 2 关 |

冷却从蓄力完成、技能效果生成时开始。解锁读取本地通关记录。

### 各关变化与波次

| 关卡 | 近战伤害倍率 | 普通／快速僵尸实际伤害 | 生命倍率 → 实际因子 | 初始现金 | 固定条目（等待数） | 队列出怪数 |
| --- | ---: | --- | --- | ---: | ---: | ---: |
| 第 1 关 | 1 | 10／20 | 1 → 1 | 100 | 66（10） | 764 |
| 第 2 关 | 1.25 | 12／25 | 1.25 → 1 | 100 | 68（10） | 794 |
| 第 3 关 | 1.5 | 15／30 | 1.5 → 1 | 100 | 68（10） | 816 |
| 第 4 关 | 1.75 | 17／35 | 1.75 → 1 | 100 | 68（10） | 835 |

各关初始 **XP 均为 0**。近战伤害按“基础伤害 × 关卡倍率”后截整数；生命倍率则**先截整数再相乘**，因此默认四关中五类僵尸的生命均与上表相同。

僵尸基地生命从阈值上方降到阈值或以下时，触发额外增援：

| 关卡 | 基地 13,000 生命 | 基地 9,000 生命 | 基地 5,000 生命 | 增援数／合并队列数 |
| --- | --- | --- | --- | --- |
| 第 1 关 | 普通 20 | 普通 30＋肥胖 1 | 普通 40＋快速 3＋肥胖 1 | 95／859 |
| 第 2 关 | 普通 30 | 普通 40＋肥胖 1 | 普通 50＋快速 5＋肥胖 2 | 128／922 |
| 第 3 关 | 普通 40 | 普通 50＋肥胖 2 | 普通 60＋快速 6＋肥胖 3 | 161／977 |
| 第 4 关 | 普通 40＋食尸鬼 10 | 普通 50＋肥胖 3 | 普通 60＋快速 7＋肥胖 3＋投尸者 1 | 174／1,009 |

出怪数是配置队列的计划数量，不含等待、基地及尸弹落地生成的普通僵尸；合并队列数按三个增援均触发计算。增援调用逐项插入队首，因此同次调用的执行顺序与配置列出顺序相反。波次 `delay` 是先截整数的**调度值**，不是直接的战斗 tick 数，也不是现实秒数；详见[配置参考](config/README.md)中的时序与队列规则。

默认队列**有限，按时间调度**，不会等待场上僵尸清空才推进。四关固定队列尾段均为 **20 肥胖 → 100 普通 → 3 投尸者 → 20 快速 → 50 肥胖**。固定队列结束，不代表基地生命触发的增援或尸弹产生的普通僵尸也被关闭。

## 下载游玩

在 [Releases](https://github.com/learner20230724/zombie-builders-rebuild/releases/latest) 下载最新版本。

- **Windows 桌面包（`desktop-win-x64`）**：**完整解压** ZIP 后双击 **ZombieBuilders.exe**。无需另开浏览器、安装 Node.js、保持终端窗口或启动本地 HTTP 服务。请保留 EXE 旁的 DLL、`locales` 与 `resources`；不是只复制一个 EXE 的单文件程序。
- **网页便携包**：解压后，在已安装 **Node.js 20 或更新版本**的环境中运行 `npm start`。

**仅网页包**需要浏览器打开 **http://127.0.0.1:8318/**，游玩时保持服务器运行。

桌面配置与存档保存在安装目录之外的 **`%APPDATA%\ZombieBuilders`**。其中 `config` 子目录的五份 JSON 仅在首次使用时复制，不覆盖已有文件。按 **F1** 查看位置，按 **F11** 切换全屏。桌面与浏览器数据相互独立，旧网页存档不会自动导入。

## 从源码运行

安装 **Node.js 20 或更新版本**，然后运行：

```sh
git clone https://github.com/learner20230724/zombie-builders-rebuild.git
cd zombie-builders-rebuild
npm start
```

浏览器打开 **http://127.0.0.1:8318/**。Windows 用户也可以双击 **Start-Game.cmd**。启动不需要 `npm install`。请通过本地服务器访问，不要直接打开 `index.html`。

## 二次开发与配置

点 **⚙ 自定义** 或按 **F2** 开关设置。宽屏为**游戏在左、设置在右**，窄屏为游戏在上、设置在下，不遮住游戏。打开默认暂停，点 **“继续战斗”** 可保持面板打开、边玩边调，点 **“暂停战斗”** 再次暂停。可用 F2、关闭按钮，或焦点在设置内时按 Esc 关闭。

六个分类为“沙盒 / 刷怪、兵种、僵尸、建筑、技能、关卡 / 出怪”，字段表列出默认值、修改值、单位和生效时机。**编辑或继续战斗不会自动应用草稿**，仍须点 **“应用本局”**；保存预设也是独立操作。

| 操作 | 效果 |
| --- | --- |
| 保存规则 | 保存一套命名规则，不改变当前战局 |
| 载入／导入预设 | 只载入可编辑草稿，不自动应用，也不覆盖其他预设 |
| 应用本局 | 立即应用支持热更新的字段，本局标为自定义 |
| 开始自定义战局 | 按完整草稿重新开始指定关卡 |
| 恢复原版默认 | 仅重置编辑草稿，不自动应用，不删除预设 |
| 回到原版模式 | 结束当前战局，返回原版模式；保留预设 |
| 导出 JSON | 下载 JSON 文件，方便备份与分享 |

**试试一键刷怪：**进入“沙盒 / 刷怪”，选一关并点“开始自定义战局”；再按 F2，点“继续战斗”，每点一下“肥胖僵尸”就增加一只，可在旁边直接看它行动。刷怪需要已经开始一局自定义战斗。

### 哪些修改立即生效？

| 设置 | 当前战局如何处理 |
| --- | --- |
| 生命 | 选“保留生命百分比”（默认）或“仅新单位”；不会复活已死亡单位 |
| 伤害、移速、碰撞范围、费用 | 后续行为使用新值；已在飞行中的投射物保留旧伤害 |
| 训练、技能蓄力与冷却 | 保留剩余进度比例，不把已完成的工作重新开始 |
| 废料场收入／间隔、每座房车人口 | 实时规则；保留已有现金与单位，收入池保留进度 |
| 收割机伤害／范围、列出的能力开关 | 后续战斗 tick／动作生效，含已在场的收割机 |
| 建筑数量上限 | 本局生效；降低上限仅阻止新订单，不拆建筑、不取消已付订单 |
| 招募人口、前置条件、技能解锁 | 下一局生效；已支付订单不退款、不重复收费 |
| 当前关卡波次 | 按稳定组 ID 本局更新，扣除已调度数量，不重播已完成组 |
| 开局现金／XP、增援定义、其他关卡波次 | 下次开始对应战局生效 |

波次可启用／禁用、调整顺序，并修改类型、数量和调度 `delay`。沙盒还能控制自动队列、队列中的五类僵尸、基地增援、尸弹落地生怪，以及食尸鬼远距长跃、牧师转化、肥胖僵尸范围攻击、投尸行为等开关；经济和收割机伤害／范围也能调。**手动生成不受自动出怪开关限制**：点一下“肥胖僵尸”，立即出现一只，不改变波次顺序。

**改波次后直接点“应用本局”即可。** 已出了一部分的组，`count` 表示本局期望总量，剩余量 = `max(0, 总量 − 已调度量)`；保留在场敌人、已有计时和已入队增援，不重播已完成组，想再出一批请新增一组。面板实时显示当前组、已调度、实际已出与剩余量，不把草稿当作已生效队列。修改其他关卡，在下次开始对应关卡时生效。缺少可信组身份的旧导入规则须先新开自定义局绑定，再热改波次；其他有效属性仍可立即应用。

原版与自定义的通关、成绩分开保存，战中改规则或使用沙盒不会刷进原版记录。恢复原版不删除预设；预设保存在当前桌面用户数据或当前浏览器中。

战场交战单位（含基地）有 **1,000** 的安全上限。面板覆盖现有配置数值与上述行为开关；新增兵种、动画驱动的攻击频率或全新技能仍需修改游戏代码，并非无限制的模组引擎。

### 直接修改 JSON

源码开发修改 **[config/](config/)**；桌面发行包请修改 **`%APPDATA%\ZombieBuilders\config`**，不要修改安装目录里的副本：

| 文件 | 配置内容 |
| --- | --- |
| `units.json` | 幸存者属性、招募与解锁条件 |
| `zombies.json` | 僵尸属性与战斗设置 |
| `buildings.json` | 建筑费用、数量限制与前置条件 |
| `powers.json` | 特殊技能消耗与冷却 |
| `levels.json` | 关卡设置与僵尸波次 |

源码配置修改后运行 `npm run config:check`，再刷新网页或重启桌面应用。配置在启动时读取，与生成的游戏代码独立维护。游戏内预设另外保存，不会改写这五份 JSON。

外置 JSON 未变时，会记住已应用的自定义规则；外置 JSON 被修改后，下次启动优先使用新文件。恢复原版不会清空这些文件或预设。

字段示例、时间单位和运行结构见[二次开发指南](docs/DEVELOPMENT.zh-CN.md)。

## 常用命令

| 命令 | 用途 |

## 项目结构

```text
config/          可编辑的游戏配置
config/defaults/ 与用户改动分离的原版默认规则
desktop/         Electron 窗口、本地固定协议与桌面启动
src/             浏览器运行时、游戏逻辑与配置适配层
public/assets/   图像、字体、音频与素材清单
public/vendor/   随项目提供的第三方运行组件
scripts/         本地服务器、校验与打包工具
tests/           自动检查
docs/            开发文档
```
